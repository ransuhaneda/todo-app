# 總覽

這是一個基本的待辦事項清單，具有 React 前端和 Node.js/Express 後端。在此測試中，您需要對應用程式進行改進。您 **可以** 使用 LLM (ChatGPT、Cursor、Claude Code 等)。

## 如何執行

1. **安裝依賴**:

   ```bash
   npm install
   ```

2. **執行應用程式**:

   ```bash
   npm run dev
   ```

   此命令將同時啟動後端伺服器和前端開發伺服器。

   - 後端伺服器將在 `http://localhost:3001` 上執行。
   - 前端應用程式將在 `http://localhost:3000` 上可用。

# 應徵者評估任務

## 任務 1：元件重構與樣式設計

主要的應用程式邏輯目前都在單一檔案中。請將待辦事項清單重構為獨立、可重複使用的元件。同時，也請美化它的外觀。您可以使用任何 CSS-in-JS 函式庫或像 SASS 這樣的預處理器，但請避免為核心的待辦事項元件使用像 Material-UI 或 Bootstrap 這樣的完整元件庫。

## 任務 2：新增「編輯」與「刪除」功能

目前，您只能新增和檢視任務。請實作編輯和刪除現有待辦事項的功能。

## 任務 3：伺服器端搜尋

在頁面上新增一個搜尋/篩選輸入框。當使用者輸入時，待辦事項清單應根據輸入內容即時篩選。
